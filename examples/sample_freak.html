FREAK: a descriptor that finds its own orientation

Left: img/pinball.jpg. Right: the same picture rotated by 30 degrees and scaled by 0.8. Each view gets FAST corners and size = 31, then freak.describe. There is no orb.ic_angle call: FREAK estimates the orientation itself and writes it to keypoint.angle. The short yellow tick on each keypoint points along that angle. describe drops keypoints too close to the border, so the page uses the count it returns, not the number of corners it detected. A line joins the matches that pass the ratio test (bfmatcher.knnMatch with k = 2, ratio 0.75). Green lines agree with the known transform within 3 px, red lines do not.

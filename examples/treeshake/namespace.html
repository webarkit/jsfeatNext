Gaussian blur, bundled with Vite

This page has to go through a bundler: it imports "@webarkit/jsfeat-next" by package name, which a browser cannot resolve on its own (opened from a plain static server it fails with "Failed to resolve module specifier"). From the repository root, run npm run example:treeshake and then npm run example:treeshake:preview, or npm run example:treeshake:dev for the Vite dev server. See examples/treeshake/README.md.

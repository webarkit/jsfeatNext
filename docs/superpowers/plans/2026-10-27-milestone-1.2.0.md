# Milestone 1.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `@webarkit/jsfeat-next@1.2.0` with the TEBLID and FREAK binary descriptors, an additively tree-shakeable bundle, the imgproc bench baselines they need, and the 1.1.0 review follow-ups closed.

**Architecture:** Each descriptor is one new module `src/<module>/<module>.ts` extending `core`, attached as a singleton on `jsfeatNext` like `orb` and `gms`, ported from OpenCV 4.10.0 (`opencv_contrib/modules/xfeatures2d`) and pinned bit-exact by OpenCV fixtures. Tree-shaking is added *beside* the default namespace export, never replacing it. Adapter wiring (#136, #232) lands in `webarkit/webarkit`; this repository only tracks it.

**Tech Stack:** TypeScript (`strict`, `strictNullChecks: false`), Vite library mode (UMD + ESM), Vitest 5 (parity + bench), Python fixture generator pinned to `opencv-contrib-python==4.10.0.84`.

**Spec:** [`2026-10-14-milestone-1.1.0-design.md`](../specs/2026-10-14-milestone-1.1.0-design.md) §2 (what moved to 1.2.0), [`docs/features2d-expansion-plan.md`](../../features2d-expansion-plan.md) (decisions D5, D6/D6a, D8, D10), and the bodies of #245, #246, #168, #137, #135, #80, #232, #136.

## Global Constraints

- PRs target `dev`, never `main`; one branch per issue; conventional-commit subjects; tags are bare `X.Y.Z`.
- `npm test` green before any claim of verification; `npm run build-ts` and `npm run format-check` (via `node_modules/.bin/prettier`) clean.
- Every new file under `src/`, `tests/`, `examples/` carries the licence header: `node scripts/check-license-headers.mjs --fix`. OpenCV-derived code (`src/teblid/`, `src/freak/`) needs the **opencv** variant; today only `src/gms/` is mapped (`OPENCV_SRC` in the script) and each new module needs its own `opencv-<file>` entry plus attribution snippet.
- OpenCV comparisons, ports, fixtures and citations use **4.10.0 only**, links pinned as `.../blob/4.10.0/...`.
- No new `any` in `src/`. Every `cache.get_buffer` balanced by `put_buffer`, including on exceptions.
- Numeric parity: no "clean-up" of arithmetic in hot loops without a parity check.
- Public API preserved: `jsfeatNext.<module>` singletons, default export unchanged, covered by `tests/parity/api-surface.test.ts`.
- BEBLID and LATCH are out of scope; TEBLID engine is written concretely for the float-threshold weak learner (D6a).

## Review Focus

1. **Keypoints near any image border (TEBLID, FREAK):** boxes/sampling points that leave the integral image must be rejected explicitly or handled bit-exactly like OpenCV; never silently read garbage (the #110 failure mode).
2. **Keypoints without orientation (`angle = -1` default) in TEBLID:** behaviour is defined and documented, not "rotate the patch by -1 rad" (the ORB trap documented in `orb.describe`).
3. **Corrupted or truncated base64 tables:** module init throws on a wrong decoded length; a test pins known entries after decoding.
4. **UMD/CJS consumers after #137:** `window.jsfeatNext` and `require()` still yield the full namespace, not `{ default, imgproc, … }`.
5. **Pool exhaustion and exceptions:** a throwing `resize` or an exception mid-describe leaves the shared pool at its original node count (`tests/properties/cache.test.ts`, `tests/setup/pool-balance.ts`).

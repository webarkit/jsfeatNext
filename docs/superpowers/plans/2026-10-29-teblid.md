# TEBLID descriptor (#135) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `jsfeatNext.teblid`, a TEBLID descriptor bit-exact with OpenCV 4.10.0 at 256 and 512 bits, with a new `keypoint_t.size`.

**Architecture:** A port of **TEBLID**, not BEBLID. In OpenCV, `TEBLID_Impl` (opencv_contrib `beblid.cpp`, which has no separate `teblid.cpp`) runs the shared engine `BEBLID_Impl<ABWLParamsFloatTh>`, with float thresholds, over TEBLID's own tables. We port that one instantiation directly, with no generic engine and no BEBLID tables (spec §2, D6/D6a). It runs over a shared-pool integral image and emulates OpenCV's float32 arithmetic with `Math.fround`. Tables are decimal literals loaded into typed arrays. The module is a tree-shakeable singleton, wired like `gms`. Ground truth: fixtures from the pinned wheel, on the platform PureCV's `cpp_ref` measures on.

**Tech Stack:** TypeScript, Vitest, Vite, Python fixture generator (`opencv-contrib-python==4.10.0.84`).

**Spec:** [`docs/superpowers/specs/2026-10-29-teblid-design.md`](../specs/2026-10-29-teblid-design.md). Read it first. Section numbers below (§N) refer to it.

## Global Constraints

- PR against `dev`, from branch `feat/135-teblid`; Conventional Commits; `Refs #135` in commits, `Closes #135` in the PR.
- `npm test`, `npm run typecheck`, `node_modules/.bin/prettier --check .`, `node scripts/check-license-headers.mjs` and `npm run build-ts` green before every commit that touches code.
- OpenCV 4.10.0 only. Citations are pinned: `https://github.com/opencv/opencv_contrib/blob/4.10.0/modules/xfeatures2d/src/beblid.cpp#L<a>-L<b>`.
- Fixtures are generated only with `.venv/Scripts/python -I scripts/gen-opencv-fixtures.py`, on this Windows x86-64 machine (T5).
- No new `any`. Every `cache.get_buffer` is returned in a `finally`.
- Every module-level `new` gets `/* @__PURE__ */` (AGENTS.md, "Keep the bundle tree-shakeable"). Never write the literal annotation keyword in a comment: rolldown misreads it.
- New files under `src/teblid/` carry the **opencv-teblid** header variant; new tests, bench and example carry the **original** variant.
- Bit-exact means every byte equal. No tolerance, and no dropping fixture inputs (§6). A mismatch traced to FMA or the platform's `cos`/`sin` is reported to the maintainer, not worked around.

## Review Focus

1. **A whole patch outside the image:** a keypoint near or past a corner with a large `size`, so both boxes clamp to the frame edge. Expected: OpenCV's bits, no out-of-range read and no `NaN` → fixture cases in Task 2.
2. **An image smaller than the patch** (e.g. 24×24): every keypoint takes the clamped path. Expected: OpenCV's bits → a `tiny` fixture case in Task 2.
3. **Negative rectified coordinates** (keypoints at x < 1 with rotation): `CV_ROUNDNUM` truncates toward zero, which is not `Math.round` → covered by the border cases of Task 2, plus a unit test in Task 4.
4. **`count` larger than `corners.length`**, or a `corners[i]` that is not a keypoint. Expected: a `RangeError` naming the count, before any buffer is borrowed → Task 4.
5. **A source that is not `U8C1`** (an `F32` or `C3` matrix). Expected: a `TypeError`; OpenCV converts colour, we do not (§2 non-goal) → Task 4.

### Task 4: the TEBLID engine

**Files:**
- Create: `src/teblid/teblid.ts`, `tests/parity/teblid.test.ts`, `tests/properties/teblid.test.ts`

**Interfaces:**
- Consumes: `TEBLID_256` and `TEBLID_512` (Task 3); `keypoint_t.size` (Task 1); `imgproc.compute_integral_image(src, sum, null, null)` with a `(w+1)×(h+1)` `Int32` sum.
- Produces: `export class teblid extends jsfeatNext` (the `core` base), with `describe(src: matrix_t, corners: keypoint_t[], count: number, descriptors: matrix_t, options?: TeblidOptions): void` and `export interface TeblidOptions { bits?: 256 | 512; scale_factor?: number }`.

- [ ] **Step 1: Write the failing parity test** `teblid.test.ts`.
  - For every fixture and case, build the image, and keypoints `new keypoint_t(x, y, 0, 0, angle, size)` with `angle = deg === -1 ? -1 : Math.fround(deg) * 0.017453292519943295`.
  - Describe with `{ bits, scale_factor }`.
  - Assert the hex of each output row equals the fixture's, naming the case and keypoint index on failure.
- [ ] **Step 2: Write the failing property tests** `tests/properties/teblid.test.ts`.
  - `size` of `0` or `-3` at index 2 throws a `RangeError` whose message contains `"2"`.
  - `count = 0` leaves the descriptors with 0 rows.
  - Angle `-1` and angle `0` give identical bits.
  - Angle `Math.PI / 2` gives different bits from `0` for an interior keypoint.
  - Only `corners[0..count)` are read: appending a junk keypoint after `count` changes nothing.
  - `bits: 128` throws.
  - `count > corners.length` throws a `RangeError` before borrowing; check the pool size before and after.
  - A non-`U8C1` source throws a `TypeError`.
  - A `size <= 0` keypoint thrown mid-list leaves the shared pool balanced.
  - Unit `roundnum`: `-0.7 → 0` and `-1.6 → -1`, as `(int)(x + 0.5f)`.
- [ ] **Step 3:** Run both test files. Expected: FAIL.
- [ ] **Step 4: Implement `describe`, following §5 exactly.**
  - Integral image from the shared pool, released in a `finally`.
  - `rectify` per keypoint, into a scratch `Int32Array` of `5n`, from the pool.
  - The border test, then the clamped path or the fast path.
  - Output bits MSB-first; `descriptors.resize(n / 8, count, 1)`.
  - Every float expression of `rectifyABWL`, `isKeypointInTheBorder` and `computeABWLResponse` is `Math.fround`-ed after each operation, in C++ evaluation order.
  - TSDoc: cite each upstream function by pinned line range; include OpenCV's `scale_factor` table and the caller-fills-`size` example from §4; describe the angle convention of §5.
- [ ] **Step 5:** Run both test files. Expected: PASS.
  - If any parity byte differs, find the first differing keypoint and bit, and compare the intermediate float32 values with a Python probe on the same input.
  - If the cause is FMA or the platform's `cos`/`sin`, **stop and report to the maintainer** (Global Constraints).
- [ ] **Step 6:** `npm test`, typecheck, Prettier. Commit `feat(teblid): TEBLID descriptor, bit-exact with OpenCV 4.10.0 (#135)`.
